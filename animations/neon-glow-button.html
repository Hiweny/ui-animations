霓虹发光按钮

描边与文字带霓虹光晕并持续呼吸，悬停时整颗按钮亮起白光、背景透出色彩。用 box-shadow 内外双层 + color-mix 控制光晕强度。

本仓库原创

深链地址：https://hiweny.github.io/ui-animations/animations/neon-glow-button.html

HTML + CSS · 一键复制 
<button class="btn-neon" type="button">Neon</button>

<style>
.btn-neon {
  --c: #22d3ee;
  padding: 0.9em 2em;
  border: 2px solid var(--c);
  border-radius: 12px;
  background: transparent;
  color: var(--c);
  font: 700 16px/1 system-ui, sans-serif;
  letter-spacing: 0.1em;
  text-transform: uppercase;
  cursor: pointer;
  text-shadow: 0 0 8px color-mix(in srgb, var(--c) 70%, transparent);
  box-shadow:
    0 0 8px color-mix(in srgb, var(--c) 60%, transparent),
    inset 0 0 8px color-mix(in srgb, var(--c) 35%, transparent);
  animation: neon-pulse 2.2s ease-in-out infinite alternate;
  transition: color 0.3s ease, background 0.3s ease, box-shadow 0.3s ease;
}
.btn-neon:hover {
  color: #fff;
  background: color-mix(in srgb, var(--c) 18%, transparent);
  box-shadow:
    0 0 22px var(--c),
    inset 0 0 16px color-mix(in srgb, var(--c) 45%, transparent);
  animation-play-state: paused;
}
@keyframes neon-pulse {
  from { filter: brightness(0.92); }
  to   { filter: brightness(1.18); }
}

@media (prefers-reduced-motion: reduce) {
  .btn-neon { animation: none; }
}
</style>
