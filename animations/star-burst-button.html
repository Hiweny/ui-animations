点击星星爆裂按钮

点击按钮时从中心向四周迸射出 12 颗小星星，呈放射状飞散并淡出。星星由 JS 动态生成，飞行距离与角度随机。

buttonstarclick
HTML + CSS + JS 
<button class="btn-burst" type="button">点我放星星</button>

<style>
.btn-burst {
  position: relative;
  padding: 0.9em 1.9em;
  border: 0;
  border-radius: 999px;
  font: 700 17px/1.2 system-ui, sans-serif;
  color: #4a2c00;
  cursor: pointer;
  background: linear-gradient(135deg, #fde68a, #fbbf24);
  box-shadow: 0 12px 26px -14px #f59e0b;
  transition: transform 0.15s ease;
}
.btn-burst:active { transform: scale(0.96); }
.burst-star {
  position: absolute;
  top: 50%;
  left: 50%;
  width: 10px;
  height: 10px;
  margin: -5px;
  background: #fbbf24;
  clip-path: polygon(50% 0, 62% 38%, 100% 50%, 62% 62%, 50% 100%, 38% 62%, 0 50%, 38% 38%);
  pointer-events: none;
  animation: burst 0.9s ease-out forwards;
}
@keyframes burst {
  0%   { transform: translate(0, 0) scale(0.4) rotate(0deg); opacity: 1; }
  100% { transform: translate(var(--x), var(--y)) scale(1.1) rotate(160deg); opacity: 0; }
}

@media (prefers-reduced-motion: reduce) {
  .burst-star { display: none; }
}
</style>

<script>
document.querySelectorAll('.btn-burst').forEach(function (btn) {
  btn.addEventListener('click', function () {
    for (var i = 0; i < 12; i++) {
      var s = document.createElement('span');
      s.className = 'burst-star';
      var ang = (Math.PI * 2 * i) / 12;
      var dist = 42 + Math.random() * 40;
      s.style.setProperty('--x', Math.cos(ang) * dist + 'px');
      s.style.setProperty('--y', Math.sin(ang) * dist + 'px');
      btn.appendChild(s);
      setTimeout(function (el) { return function () { el.remove(); }; }(s), 900);
    }
  });
});
</script>
