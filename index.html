UI 动效画廊

翻转美食卡片

美食卡片，悬停时整体翻面，背面有一条橙色光带持续旋转扫过；正面展示菜品名称、标签与份量信息。

cardflipfoodhover

展开天气卡片

白色天气卡片，悬停时卡片变黄并向下展开，露出湿度、风速、空气质量、体感温度与气压等详细数据。

cardweatherhoverexpand

翻转银行卡

拟真银行卡，鼠标悬停时整张卡片绕 Y 轴翻转 180°，露出背面的磁条与安全码。正面有芯片、感应标识与卡号。

cardflip3d

渐变光晕卡片

深色卡片背后垫着一层青紫渐变光晕，悬停时光晕旋转并放大、模糊加深，呈现出流动的霓虹质感。

cardgradientglowhover

玻璃拟态天气卡片

毛玻璃质感的天气卡片，半透明背景叠加深度模糊，展示城市、天气状况、当前温度以及最低/最高温。

cardglassmorphismweather

星空隧道背景

Canvas 绘制的 3D 星空隧道，800 个粒子从远处飞向镜头。粒子随机为实心星、描边星、圆点、十字、光晕、闪光六种形态，配六种霓虹色并各自旋转、闪烁。

backgroundcanvasstar3d

流星星空背景

斜向流星从左上方划向右下，配合四散分布的星点呼吸式闪烁。流星用渐变色条 + translate3d 位移，星星用透明度与缩放模拟眨眼。

backgroundstarmeteortwinkle

彩虹光晕开关

开关背后是一团由多个彩色径向渐变叠加、模糊 20px 的光晕，整个开关还带轻微的 3D 摆动。拨动时滑块滑到另一侧，轨道变深色。

switchtogglegradient

花朵绽放按钮

按钮四周藏着六朵小花，悬停时花瓣变大并绕着各自中心缓慢自转，文字底色同时变浅。每朵花由四片花瓣用 grid 拼成。

buttonflowerhover

霓彩光晕按钮

按钮底色是青粉蓝三色渐变，悬停时背后的一圈锥形彩虹光晕会模糊扩散开来，像极光从边缘溢出。

buttongradientglow

渐变流光描边

用 @property 注册角度变量，让一圈 conic-gradient 描边持续旋转，悬停时整圈发光。现代 CSS 单元素实现，无需伪元素堆叠。

buttonbordergradient

流光扫过按钮

一条倾斜的高光带沿按钮表面循环扫过，像金属反光。用 ::before 伪元素 + skewX 实现，不增加任何多余 DOM。

buttonshimmerhover

点击涟漪按钮

点击位置生成一圈白色涟漪扩散淡出，模拟水面波纹。涟漪大小按按钮尺寸计算，位置跟随鼠标落点。

buttonrippleclick

流光渐变文字

文字用四色渐变填充并循环流动，像液态金属反光。靠 background-size 放大后用 background-position 位移实现无缝循环。

textgradientflow

点击星星爆裂按钮

点击按钮时从中心向四周迸射出 12 颗小星星，呈放射状飞散并淡出。星星由 JS 动态生成，飞行距离与角度随机。

buttonstarclick

星星闪光按钮

按钮四角藏着四颗小星星，鼠标悬停时依次旋转、放大、闪烁，图标同时旋转放大。纯 CSS 驱动，靠 --i 变量错开每颗星的动画延迟。

buttonstarsparklehover
