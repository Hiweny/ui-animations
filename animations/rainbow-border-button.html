彩虹旋转描边按钮

按钮背后藏着一个 conic-gradient 彩虹环，持续旋转，只在边缘露出 2px 成为流动的彩色描边。用 z-index 分层实现，无需 mask。

本仓库原创

深链地址：https://hiweny.github.io/ui-animations/animations/rainbow-border-button.html

HTML + CSS · 一键复制 
<button class="btn-rainbow" type="button"><span>Rainbow</span></button>

<style>
.btn-rainbow {
  position: relative;
  z-index: 0;
  padding: 0.9em 2.2em;
  border: 0;
  border-radius: 999px;
  font: 700 17px/1.2 system-ui, sans-serif;
  color: #e5e7eb;
  cursor: pointer;
  background: #0b1020;
  transition: color 0.3s ease;
}
.btn-rainbow::before {
  content: '';
  position: absolute;
  inset: -2px;
  border-radius: inherit;
  z-index: -1;
  background: conic-gradient(#f43f5e, #f59e0b, #22d3ee, #a855f7, #f43f5e);
  animation: rainbow-spin 3s linear infinite;
}
.btn-rainbow:hover { color: #fff; }
@keyframes rainbow-spin {
  to { transform: rotate(360deg); }
}

@media (prefers-reduced-motion: reduce) {
  .btn-rainbow::before { animation: none; }
}
</style>
