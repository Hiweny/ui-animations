流光渐变文字

文字用四色渐变填充并循环流动，像液态金属反光。靠 background-size 放大后用 background-position 位移实现无缝循环。

textgradientflow
HTML + CSS 
<div class="text-flow">Star Flow</div>

<style>
.text-flow {
  font: 800 38px/1.2 system-ui, sans-serif;
  letter-spacing: -0.01em;
  background: linear-gradient(90deg, #818cf8, #22d3ee, #f472b6, #818cf8);
  background-size: 200% 100%;
  -webkit-background-clip: text;
  background-clip: text;
  color: transparent;
  animation: text-flow 4s linear infinite;
}
@keyframes text-flow {
  to { background-position: -200% 0; }
}

@media (prefers-reduced-motion: reduce) {
  .text-flow { animation: none; }
}
</style>
