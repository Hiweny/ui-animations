星环环绕按钮

五颗小星星沿一个圆形轨道持续环绕按钮旋转，像行星轨道。用绝对定位 + rotate/translateX 组合，并用 --a 变量给每颗星设置负延迟错开起始角度。

灵感：The Galaxy Button（重写实现） 查看灵感来源 ↗

深链地址：https://hiweny.github.io/ui-animations/animations/orbiting-stars-button.html

HTML + CSS · 一键复制 
<button class="btn-galaxy">
  <i class="orbit-star" style="--a:0"></i>
  <i class="orbit-star" style="--a:72"></i>
  <i class="orbit-star" style="--a:144"></i>
  <i class="orbit-star" style="--a:216"></i>
  <i class="orbit-star" style="--a:288"></i>
  <span>Galaxy</span>
</button>

<style>
.btn-galaxy {
  position: relative;

  font: 700 17px/1.2 system-ui, sans-serif;

  cursor: pointer;

  box-shadow: 0 12px 30px -14px #6366f1;

}
